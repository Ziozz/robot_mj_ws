# upperbody-bridge 参考说明

本项目参考了本机 `/home/zzz/upperbody-bridge` 的轨迹接口设计，但该工程对应另一台
机器人，不复制其硬件参数和关节映射。

参考的通用设计：

- `MoveJ.cpp` 使用 2 ms 插补周期；本项目也输出严格固定的 2 ms 时间戳。
- `MoveJ.cpp` 使用同一个归一化位移比例计算全部关节，因此关节共享起止时刻；本项目
  用 TOPP-RA 的公共路径参数实现同样的同步性质。
- 其阻抗入口使用期望位置、速度、加速度；本项目的轨迹对象同时提供三者。
- 其命令包含时间戳和关节数组；本项目通过 `joint_names` 明确顺序，未来 ROS 2 bridge
  必须按名称重排，禁止默认假定数组顺序相同。

没有复制的内容：

- `4π/3 rad/s`、`π rad/s²`、`0.75π rad/s³` 是另一台机器人的 MoveJ 参数。
- LCM 关节索引、KP/KD、碰撞阈值和力控参数不适用于 G1。
- upperbody-bridge 使用七段 jerk 限制；当前 TOPP-RA 层只约束速度和加速度。后续将
  通过 Ruckig 或独立 S 曲线层加入 jerk 约束，不能把离散加速度差分当成严格 jerk 约束。
